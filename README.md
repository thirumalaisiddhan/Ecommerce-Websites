# 🛒 E-Commerce Website

A responsive and user-friendly **E-Commerce Website** built using modern web technologies. This project demonstrates an online shopping platform with an attractive user interface, product listings, shopping cart functionality, and a seamless browsing experience.

## 🌟 Features

* 🏠 Responsive Home Page
* 🛍️ Product Listing
* 🔍 Product Search
* 📂 Product Categories
* 🛒 Shopping Cart
* ❤️ Wishlist (if implemented)
* 📱 Mobile-Friendly Design
* 🎨 Modern UI/UX
* ⚡ Fast and Lightweight

## 🛠️ Tech Stack

* HTML5
* CSS3
* JavaScript
* Bootstrap (if used)

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/thirumalaisiddhan/Ecommerce-Websites.git
```

### Navigate to the Project

```bash
cd Ecommerce-Websites
```

### Run the Project

Open `index.html` in your preferred web browser.
